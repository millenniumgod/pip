# 자본주의 팔자 리포트

8문항 입력 → 현재 궤적(A)과 해야 할 일(B)을 보여주는 정적 웹페이지입니다. 서버·DB 없이 브라우저에서만 계산합니다.

- 실행: `palja/index.html`을 열거나 정적 호스팅(GitHub Pages 등)에 올리면 됩니다. 빌드 과정이 없습니다.
- 개인정보: 입력값은 저장·전송하지 않습니다. CSP(`connect-src 'none'`)로 외부 요청도 차단합니다.
- 테스트: `node palja/test/engine.test.js`

## 구조
| 파일 | 역할 |
|---|---|
| `data.js` | 연도별 통계, 직무·직장 기준값, 모델 가정 |
| `engine.js` | 시뮬레이션과 경우의 수 탐색(수만 가지 조합 → B 선택) |
| `app.js` | 폼, 결과 렌더링, 이미지 저장·공유 |

## 공개 전 확인할 것
- `data.js`의 실업률·GDP·물가는 근사치입니다. 통계청(KOSIS)·한국은행(ECOS) 원자료와 대조하세요.
- 직무별 노동 수명, 저축률, 수익률 등 가정값은 임의 설정이므로 검토가 필요합니다.
- 결과 문구는 "공개 통계 기반의 추정 모델"로 안내하며, 투자 권유나 상담이 아님을 표시합니다.
